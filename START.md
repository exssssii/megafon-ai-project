# С чего начать

Агент помогает пройти путь от размытого запроса до продуктовой и коммуникационной стратегии с планом проверки. Подготовка занимает пару минут.

## Подготовка, один раз

Нужны `uv` и сеть. Python 3.12 `uv` скачает сам, если его нет. Откройте терминал в этой папке.

**Windows**, в PowerShell:

```powershell
$env:UV_PYTHON_INSTALL_DIR = "$PWD\.python"
uv sync --locked --managed-python
```

`uv` один раз скачает Python 3.12, около 21 МБ, в папку `.python` рядом с агентом. Это нужно для Codex: его песочница на Windows не запускает Python из вашего профиля пользователя. Claude Code работает с той же установкой. Если папка `.venv` уже есть, команда её пересоберёт.

**macOS и Linux:**

```text
uv sync --locked
```

Если вы пропустите этот шаг, агент скажет об этом сам.

Что учесть в вашей среде:

- **Codex:** для чтения сайтов нужен поиск в интернете. Запускайте `codex -c web_search=live`. Без поиска агент работает с вашими файлами и скажет, что сайты недоступны. Если терминал не находит команду `codex`, так бывает, когда Codex установлен приложением, найдите её так:

  ```powershell
  $codex = (Get-ChildItem "$env:LOCALAPPDATA\OpenAI\Codex\bin" -Recurse -Filter codex.exe | Select-Object -First 1).FullName
  & $codex -c web_search=live
  ```
- **Codex на Windows:** при первом запуске Codex предложит настроить песочницу. Выберите «Set up default sandbox» и подтвердите запрос администратора. Потом Codex может спрашивать разрешение почти на каждую команду, даже на чтение файлов этой папки. Отвечайте «Yes, proceed». Вариант «don't ask again» не обязателен.
- **Claude Code:** при первых запусках утилит и открытии сайтов приложение попросит разрешения. Это обычная проверка, разрешите команды из этой папки.

Другие среды, например Cursor, Windsurf или GitHub Copilot, тоже подходят, если читают `AGENTS.md` и могут запускать команды в терминале этой папки. Полностью проверены только Claude Code и Codex. В других средах лимит поиска держится без автоматической защиты, а расход и версия среды записываются, только если среда их показывает.

## Начать

1. Откройте эту папку в Claude Code, Codex или другой совместимой среде.
2. Напишите задачу своими словами и укажите файлы, если они есть. Например:

> Почему падает удержание в нашем сервисе доставки? Вот выгрузка заказов и заметки по интервью, решение нужно к концу месяца.

Шаблоны и команды не нужны. Агент покажет, как понял задачу, и попросит подтвердить. Исследование начнётся после вашего ответа. Если подтверждение не нужно, так и напишите: «сразу исследуй».

## Управлять работой

Пишите обычными словами:

| Что нужно | Что написать |
|---|---|
| Прерваться | «Остановись» |
| Вернуться, в том числе в новом чате | «Продолжи кейс» |
| Изменить условие | «Цену менять нельзя» |
| Отказаться от варианта | «Не согласен, берём другой» |
| Доверить выбор агенту | «Реши сам, бери рекомендованный» |
| Спросить об основании | «Почему рекомендован второй вариант?» |
| Спросить о принятом решении | «Кто отвечает за запуск?», «Что мы обещали к декабрю?» |
| Передать новые данные | «Вот свежая выгрузка, посмотри, что она меняет» |

В конце каждого этапа агент пишет, что готово, что будет дальше и нужно ли что-то от вас. Существенный выбор всегда остаётся за вами: его можно сделать самому или явно передать агенту, тогда он возьмёт свою рекомендацию и скажет, от чего отказываемся. После стратегий агент записывает, что делаем, кто отвечает, к какому сроку и когда решение пересматриваем: вы утверждаете этот документ вместе с порогами проверки, одним вопросом. Ответственных и сроки он только предлагает, вы их правите. Если позже придут новые данные, он покажет, какие выводы они меняют и что не затронуто, дождётся вашего выбора и перепишет только затронутое, а прежние версии сохранит. Агент ничего не публикует и не отправляет.

Всё по задаче хранится в `projects/<название кейса>/`. Папку можно перенести между Claude Code и Codex, работа продолжится с того же места.

## Какие материалы подходят

Документы DOCX и PDF с текстом, таблицы XLSX и CSV, заметки MD и TXT, ссылки на открытые страницы. Скан без текста, страницу со входом или собранную скриптом агент не прочитает и скажет об этом. Сохраните такую страницу или выгрузку файлом и передайте его.

## Если что-то пошло не так

- Агент просит выполнить подготовку или говорит, что окружение в папке не запускается: выполните подготовку для своей системы из начала этого файла и повторите реплику.
- Агент говорит, что файл не прочитан или не добавлен: файл остаётся на месте, попросите повторить или передайте другой формат.
- Новый чат не находит работу: напишите «Продолжи кейс» и название кейса. Если кейсов несколько, агент спросит, какой.
- Codex не открывает сайты: проверьте, что включён поиск в интернете.

Команды для самостоятельной проверки, доступы и платность — в [`README.md`](README.md#если-что-то-не-работает).
