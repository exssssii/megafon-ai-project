# Заметки о сервисе «Книжная полка»

## Условия обмена

Жители приносят прочитанные книги и берут чужие бесплатно. Один участник может взять не больше трёх книг за визит.

## Работа пунктов

Сейчас открыто четыре пункта обмена, они работают по субботам.

## Расходы

Аренда одного пункта составляет 3000 условных единиц в месяц.
