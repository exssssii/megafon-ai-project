# Изображения и наблюдения

Связь: [общий контракт](README.md), [вид записи источника](records/source.md).

Расширение перечислений `type` и `locator.kind` не меняет версию формата: кейсы без изображений читаются без изменений.

- **Регистрация.** `tools/read_material.py add` принимает `.png`, `.jpg`, `.jpeg`, `.webp`. Формат проверяется по заголовку, а не по расширению; читаются формат, ширина и высота, пиксели и содержимое не читаются. Подделанное расширение, обрезанный файл (у PNG в последних 64 байтах нет блока `IEND`, у JPEG нет маркера конца `FF D9`) и анимация (WebP с флагом анимации, PNG с блоком `acTL`; причина «анимация не поддерживается») — код 2, источник не записывается. Сторона больше `max_image_side` — как у других форматов: источник записывается со статусом чтения `over_limit`, код 3, наблюдения для него не принимаются. После успешного `add` источник `partial`, `complete: false`, блоков нет, в `limits` «Изображение PNG 1366×768. Наблюдения не записаны.»; файл `sources/extracted/<SRC-id>.jsonl` пустой, `EXTRACT_MISSING` не выдаётся. Очень высокое изображение (высота больше ширины в 2,5 раза) получает в `limits` пометку, что детали могут потеряться.
- **Наблюдения.** Агент смотрит изображение и пишет файл `sources/incoming/<имя>.md`, `tools/read_material.py add-observations <case> <SRC-id> --text-file <файл>` разбирает его и пишет блоки `region`. Формат файла: `## Экран` (метка `целевой`, `заслонён`, `вход`, `капча`, `ошибка`, `пусто` или `другое` и одна строка), `## Наблюдение N` с N с единицы подряд (три строки `Где:`, `Видно:`, `Текст:`; строка `Текст:` — либо ровно `нет`, либо ровно `неразборчиво`, либо только цитаты в «…», разделённые запятыми, точками с запятой или пробелами; всё вне кавычек — ошибка формата), `## Не разобрано` (обязателен, допустим `нет`). Блок: `{"n": N, "locator": {"kind": "region", "index": N, "area": "<строка Где>"}, "text": "Где: …
Видно: …
Текст: …"}`. `quote` проверяется только по части блока после `Текст:`: место (`Где:`), описание (`Видно:`) и сами метки не цитируются.
- **Статусы.** Метка не `целевой`: `unavailable`, блоков нет (выход 2). Метка `целевой`: нужно хотя бы одно наблюдение, статус `ok`, если `## Не разобрано` — `нет` и снято всё, иначе `partial`. Повторная команда переписывает наблюдения, пока на источник нет ссылок; после ссылки — отказ (код 4), источник отзывают и регистрируют заново.
- **Снимки страниц.** `tools/read_material.py capture-web <case> --url <адрес> --title <название> [--mobile]` (необязательная группа `screenshots`) записывает части страницы как источники `image` с `origin: public_web`, `location.path` вида `sources/capture-<SRC-id>.png`, общими `source_url` (адрес после переадресации) и `retrieved_at` и названием «<название>, экран i из n». Все части попадают в реестр одной записью. Если снята не вся страница, у последней части в `sources/extracted/<SRC-id>.report.json` стоит `capture_incomplete` («Снято k из n экранов.»), статус остаётся `partial`, а `add-observations` сохраняет эту пометку в начале `limits` и не поднимает статус до `ok`. Адрес и каждый шаг цепочки переадресаций проверяются правилом публичных адресов, запросы страницы пропускаются только к публичным адресам, всплывающие окна закрываются, сокеты не соединяются. Правило применяется к имени, которое видит программа, а браузер разрешает его сам ещё раз, поэтому защита от подмены ответа DNS между двумя разрешениями не гарантируется (ограничение записано в [environments.md](../../docs/environments.md#изображения-e04)). Весь снимок ограничен `capture_timeout_seconds` плюс запас: по истечении браузер останавливается, ответ — `timeout`.
- **Признаки отказов.** `capture_unavailable` (нет Playwright или браузера, в ответе поле `install` с двумя командами), `budget_exhausted`, `action_missing` и `fetch_error`: `network_unavailable`, `address_blocked`, `http_error`, `timeout`, `blank_page`, `capture_unreadable`.
- **Утверждения.** `region` допустим только для `image` (иначе `LOCATOR_MISMATCH`), несуществующий номер наблюдения — `LOCATOR_NOT_FOUND`, цитата не из наблюдения — `QUOTE_NOT_FOUND`. Правила, что из наблюдений факт, а что гипотеза, — [методика](../knowledge/ux-review.md).
