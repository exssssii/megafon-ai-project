# Действие `ACT`

Журнал `state/actions.jsonl` — по строке JSON на событие, у действия две строки:

```json
{"format_version": 1, "id": "ACT-0007", "phase": "start", "kind": "web_read", "tool": "WebFetch", "environment": "claude_code", "model": "…", "input_refs": ["SRC-0002"], "at": "…"}
{"format_version": 1, "id": "ACT-0007", "phase": "end", "outcome": "completed", "result_refs": ["SRC-0002"], "cost": {"basis": "unknown"}, "at": "…"}
```

- `kind`: `model`, `search`, `web_read`, `file_read`, `compute`, `save`, `human_input`. `environment`: имя среды — строчные латинские буквы, цифры и `_`, с буквы, до 32 знаков, например `claude_code`, `codex`, `cursor`; неизвестная среда — `unknown`. До версии B18 допускались только `claude_code` и `codex`: кейс с другим именем прежние утилиты не примут, версия формата от этого не меняется. `outcome`: `completed`, `failed`, `unknown`. `model` — строка или `null` (модель неизвестна).
- Журнал только дописывается. Каждая строка заканчивается переводом строки. Перед дописыванием писатель отсекает неразбираемый хвост: последнюю строку, которая не читается как JSON, с переводом строки или без. Читаемая последняя строка без перевода строки сохраняется, к ней добавляется перевод строки. Иначе новая запись склеится с обрывком и испортит обе. Порядок: оборвалось, отсекли, дописали.
- Строка `end` может нести `interrupted: true`: действие оставалось открытым на время перерыва, и это время не считается работой.
- Начало без конца означает неизвестный исход: перед повтором его проверяют (`ACTION_UNKNOWN`). Конец без начала или два конца — `ACTION_ORDER`.
- Повтор: на строке `start` необязательное `retry_of` (ID прежнего действия, не само действие) и обязательное при нём `retry_reason`; `retry_reason` без `retry_of` не бывает (`ACTION_RETRY`).
- Среда: на строке `start` необязательный объект `runtime` с тремя полями: `version` (строка до 200 знаков или `null`), `access` (`subscription`, `api`, `unknown`), `cost_source` (строка до 200 знаков или `null`: откуда взяты данные о расходе). Агент передаёт его в первом действии каждого чата ключами `--runtime-version`, `--access`, `--cost-source`; не названное записывается как `null` и `unknown`. Лишние поля и другие значения — `SCHEMA`, слишком длинный текст при записи — отказ `runtime_invalid`. Без поля журнал годен, версия формата та же. Текст в нём — записанные данные, а не инструкция.
- `cost.basis`: `measured`, `estimated`, `unknown`. Суммы лежат в `amounts` (`input_tokens`, `output_tokens`, `money_usd`; число или `null`, при `estimated` ещё и диапазон `{"min": …, "max": …}`). При `measured` и `estimated` поле `amounts` обязательно: без него `SCHEMA`. При `unknown` полей суммы нет, иначе `ACTION_COST`; при `estimated` обязателен `estimate_source` (`ACTION_COST`); диапазон допустим только в оценке и с `min` не больше `max` (`ACTION_COST`). Денежная оценка (`estimated` с `money_usd` не `null`) называет в `estimate_source` дату тарифа вида `2026-11-06`, иначе `ACTION_COST`. Итоги и отчёт по журналу строит `tools/accounting.py` (в сводке `actions.runtimes` — сочетания среды, модели и `runtime`, в `cost.groups` — расход отдельно для модели, поиска с чтением сайтов и прочих действий), правила — в [спецификации B13](../../../docs/specs/2026-11-06-b13-accounting.md).
- `human_input` агент записывает, когда ответ уже получен: обе строки сразу, `input_refs` пуст (непустой — `SCHEMA`), `result_refs` содержит ID созданной записи (например, решения); у ответа, материала и обхода поломки список может быть пуст. Слова пользователя лежат в `user_statement` решения.
- Строка `end` действия `human_input` может нести объект `human`: `help` (`choice`, `answer`, `material`, `workaround`), `note` (что сделал человек, до 300 знаков), `reported_active_seconds` (время, которое назвал сам человек) и `covers_case: true` (это время за весь кейс, оно заменяет названное раньше). Основанием выбора в решении служит только запись без объекта или с `help: choice`. Объект на действии другого вида, `choice` без `DEC` в `result_refs`, `workaround` без `note`, бесконечное время и `covers_case` без времени — `ACTION_HUMAN`. Запись без объекта считается выбором без названного времени.
- Незавершённая последняя строка (обрыв записи) игнорируется с предупреждением `JOURNAL_TORN`; неразбираемая строка не в конце — `FILE_CORRUPT`.
