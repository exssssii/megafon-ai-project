# Источник `SRC`

```json
{
  "id": "SRC-0001", "created_at": "2026-11-01T10:00:00+03:00",
  "record_status": "active",
  "type": "md", "title": "Заметки о сервисе",
  "location": {"path": "sources/service-notes.md"},
  "origin": "user_provided", "allowed": true,
  "retrieved_at": "2026-11-01T10:00:00+03:00",
  "sha256": "<64 hex>",
  "extraction": {"status": "ok", "complete": true, "limits": "Прочитан целиком."}
}
```

- `type`: `md`, `txt`, `docx`, `pdf`, `csv`, `xlsx`, `web`, `image`. `image` — файл PNG, JPEG или WebP: см. [изображения и наблюдения](../README.md#изображения-и-наблюдения).
- `location`: ровно одно из `path` или `url`. Для `url` `sha256` равен `null`, если текст сохранил агент (`add-web`), и равен SHA-256 скачанных байтов, если страницу скачала утилита (`fetch-web`). Для `path` это SHA-256 исходных байтов файла (без перекодировки и нормализации строк; 64 символа, строчные hex). Необязательное `source_url` хранит адрес, откуда скачан файл.
- `origin`: `user_provided`, `public_web`, `own_training`, `synthetic`. `synthetic` — беседа с модельным персонажем: путь вида `sources/interviews/synthetic-<персонаж>-<n>.md` и значение `synthetic` связаны взаимно (иначе `SYNTHETIC_PATH`), утилита чтения выводит `origin` из пути. Синтетический источник не подтверждает ничего: утверждение с ним в `supports` — только `hypothesis` и только `unconfirmed`, он не может быть входом расчёта и не может стоять в `contradicts` (модельное «не согласен» не делает утверждение спорным): всё это `SYNTHETIC_NOT_EVIDENCE`. Синтетичность — свойство происхождения текста, поэтому правило действует и для отозванного источника: беседа, заменённая повтором, не превращает гипотезы из неё в факты и не снимает пометку. `allowed: false` запрещает использовать источник как подтверждение.
- `extraction.status`: `ok`, `partial`, `empty`, `unreadable`, `unsupported`, `over_limit`, `unavailable` (последнее для сайта); `complete` — логическое; `limits` — текст границ чтения.
- Файл источника не меняется после регистрации: другой отпечаток — `SOURCE_CHANGED`, нужна новая запись источника.
- Отзыв: `record_status: "withdrawn"` и `status_reason`.

## Извлечённый текст

`sources/extracted/<SRC-id>.jsonl` создаётся командами `tools/read_material.py add`, `add-web`, `add-observations` и `capture-web`. Одна строка — блок: `n` (номер блока с единицы), `locator` (объект контракта), `text`, необязательные `heading` (ближайший заголовок), `cells` (значения строки таблицы: список для CSV, адрес → значение для XLSX), `formula_no_value` (адреса формул без сохранённого значения). `locator` копируется в `supports`, `contradicts` и `inputs` без изменений, `quote` добавляется при цитировании. При статусах без текста файла нет. Записи `SRC` создаёт эта утилита, руками их не пишут.

## Локатор

Объект с `kind`; указывает точное место в источнике. Необязательное `quote` — короткая цитата.

| `kind` | Поля | Для типов источника |
|---|---|---|
| `section` | `heading` | `md`, `txt`, `docx`, `web` |
| `paragraph` | `index` (с 1) | `docx`, `md`, `txt`, `web` |
| `page` | `page` (с 1) | `pdf` |
| `cells` | `sheet`, `range` | `xlsx` |
| `rows` | `from`, `to` | `csv` |
| `doc_table` | `table`, `row` | `docx`, `web` |
| `region` | `index` (с 1), `area` | `image` |

Индексы начинаются с единицы и считаются по извлечённому тексту: абзац отделён пустой строкой, в DOCX абзац — элемент документа. Другой вид для типа источника — `LOCATOR_MISMATCH`.

Валидатор сверяет локатор с извлечённым текстом источника (`sources/extracted/<SRC-id>.jsonl`) в утверждениях и входах расчётов, только активных:

| `kind` | Подходящие блоки |
|---|---|
| `paragraph`, `page` | у блока такой же индекс |
| `doc_table` | равны `table` и `row` |
| `region` | у блока такой же `index`; `area`, не совпавшая с `area` блока, даёт только предупреждение `REGION_AREA_DIFFERS`; `quote` ищется только в части блока после `Текст:` |
| `section` | `heading` блока равен `heading` локатора |
| `rows` | номер строки блока входит в `from`–`to` |
| `cells` | тот же лист, диапазоны пересекаются; диапазон, который нельзя разобрать, не указывает ни на что |

- Нет подходящего блока — `LOCATOR_NOT_FOUND`. Есть `quote`, но её нет в тексте ни одного подходящего блока — `QUOTE_NOT_FOUND`. Цитата сравнивается с точностью до пробельных символов, регистр важен; склейка соседних блоков не выполняется. Если цитата начинается или кончается числом (цифрой, либо знаком `.` или `,` перед цифрой), рядом не должно быть цифры, знака `.` или `,` с цифрой, а пробел считается разделителем разрядов, когда с одной стороны группа ровно из трёх цифр, с другой от одной до трёх: `140` не совпадает с `1140`, `0.140`, `1 140`, `140 000`, `.140` не совпадает с `0.140`, `,5` — с `140,5`. Фразы `2025 год` и `в 140 случаях` совпадают. Цитата из таблицы должна быть значением одной ячейки: это правило для агента, валидатор проверяет только наличие цитаты в тексте блока.
- Если вид локатора не подходит типу источника, это только `LOCATOR_MISMATCH`. Источники со статусом чтения без текста (`empty`, `unreadable`, `unsupported`, `over_limit`, `unavailable`) не проверяются. Статус источника (в том числе отзыв) на проверку не влияет.
- У источника со статусом `ok` или `partial` нет файла извлечения — предупреждение `EXTRACT_MISSING` (один раз на источник). Файл не разбирается — `FILE_CORRUPT`, прочие проверки для него пропускаются.
