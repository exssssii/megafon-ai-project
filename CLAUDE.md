# Общие правила проекта

@AGENTS.md

`AGENTS.md` — единственный источник общих правил разработки для всех участников. Если импорт не поддерживается, прочитать файл явно. Не создавать здесь вторую копию workflow.

Эти правила касаются разработки репозитория. Для использования готового агента нужно следовать его отдельной точке входа, определённой спецификацией продукта.
