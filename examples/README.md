# Учебные кейсы

Два предварительных кейса для проверки агента на разных задачах. Это не официальный бриф хакатона: когда он появится, демонстрационный кейс будет с ним сверен.

Продукты и компании вымышлены, совпадения случайны. Числа в файлах — собственные учебные данные. Сайты, указанные в запросах, настоящие и публичные.

| Папка | Вопрос руководителя |
|---|---|
| [`retention-smb`](retention-smb/request.md) | Почему просело удержание сервиса онлайн-записи |
| [`direction-b2c`](direction-b2c/request.md) | Куда развивать приложение для владельцев питомцев |

В `request.md` лежит запрос, с которого начинается работа. Основные материалы находятся в `materials/`. Папка `extra/` выдаётся только по сценарию приёмки, в обычном прогоне её не используют.

Файлы создаёт `tools/make_acceptance_cases.py`, вручную они не правятся. Запуск:

```text
uv run --group fixtures python tools/make_acceptance_cases.py
```
