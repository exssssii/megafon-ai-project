# Отчёт о приёмке ядра (B12)

Связь: [карточка B12](../tasks/CORE.md#b12-принять-обязательное-ядро), [протокол A01–A11](protocol.md), [проверки на следующем полном прогоне](b12-pending-checks.md), [доработки](../tasks/POLISH.md).

## Итог

Обязательное ядро принято на версии PR №21 (PR №21): Claude Code и Codex × `retention-smb` и `direction-b2c`, перенос в обе стороны. Сбой утилиты и повреждённое сохранение (шаги 11–12) приняты набором `faults`. В Claude Code набор `faults` прошёл на коммите 2 ветки PR №22: это ветка PR №22, где поправлено сохранение после потери.

Пользователь решил заморозить приёмку на версии PR №21. Правки, которые выросли из прогонов (PR №22 и №25), в этот зачёт не входят. Часть из них меняет поведение на шагах 1–10, поэтому вживую их проверит один полный прогон на финальном коммите. Этот прогон всё равно нужен для чистого запуска B14. Что именно в нём смотреть, записано в [списке проверок](b12-pending-checks.md).

## Ограничения

- **Правки после зачёта.** PR №22 (учёт, сохранение после потери) и PR №25 (бриф при невыполнимом требовании, расчёт «до и после», служебные слова, версия среды в журнале, предупреждение о пустом журнале) не проверены полным прогоном. Проверка — в [списке](b12-pending-checks.md), на финальном коммите вместе с B14.
- **Codex 1a, шаг 10.** Прогон шёл на версии PR №20, где время ещё называлось в секундах. Правка проверена в Codex 1b.
- **Claude Code, прогон 2.** В первой попытке агент не записал ни одного действия, и время не выросло. Во второй журнал полный. Засчитана вторая попытка; повторяемость не доказана (D16, правка в PR №25).
- **D07 закрыта:** смена сделанного выбора, предварительные стратегии и исследование с поиском прошли живьём в обеих средах в прогонах `hard` (по PR №25: строка закрывается этим отчётом).
- **Шаги 11–12** после правки сохранения проверены одним удачным прогоном `faults` в каждой среде (D29).
- **Отчёт учёта в архиве Claude Code 1a** показывает 17 минут до первого результата, верное значение после правки — 381 с (D31).
- **Стратегии до утверждения брифа.** В обоих `hard` после невыполнимого требования стратегии писались до утверждения брифа, потому что сценарий не отвечал на вопрос (D21, D25, D27, правка в PR №25).
- **Служебные слова в ответах** встречались в Codex и Claude Code (D22, правка в PR №25).
- **Просмотр результата.** Прогоны Codex просмотрел один участник команды, прогоны Claude Code — другой, каждый в своей среде. Перекрёстного просмотра чужой среды не было.
