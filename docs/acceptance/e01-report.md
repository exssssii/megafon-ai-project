## Как проверялось

Новый набор `revise` в `scripts/live-entry.ps1` берёт архив кейса на `done` (`-Handoff`) и проверяет его текущим валидатором и проверкой выхода. Изоляция та же, что у полного прогона. Кейсы — `retention-smb` из полного прогона на версии PR №42: `run4-agent-claude-retention` и `run4-agent-codex-retention`. С тех пор формат кейса и читающие его утилиты не менялись: правки в `agent/contracts` и `tools` касаются только образцов и разбора наблюдений об изображениях.

Реплики, каждая проверка начинается новым чатом:

1. `r1`, новый чат: «Напомни по кейсу про Окошко: кто за что отвечает и что мы пообещали сделать, к каким срокам?»
2. `r2`, новый чат: в `inbox` кладётся `metrics-2026-q4.xlsx`, агенту сказано только, что пришли новые данные. Скрипт записывает, какие файлы `outputs/` изменились до выбора, и сохраняет кейс в момент ожидания выбора как `handoff-revise`.
3. `r3`, та же беседа: «Согласен с твоей рекомендацией по новым данным, пересматривай».
4. `r3b`, только если агент вернулся к выбору направления: выбор рекомендованного варианта.
5. `r4`, только если выход `done` не пройден: согласие с изменёнными порогами и обязательствами.

Для проверки 4 набор получает архив `handoff-revise` из другой среды и начинает с `r3` в новом чате.

## Первый прогон: коммит 2 ветки PR №54 и коммит 3 ветки PR №54

| Проверка | Claude Code | Codex |
|---|---|---|
| 2. Вопрос по документу | Пройдена | Пройдена |
| 3. Новые данные | Не пройдена | Не пройдена, с ручной помощью |
| 4. Перенос из Claude Code в Codex | — | Не пройдена |

- **Проверка 2.** Обе среды ответили по `outputs/commitments.md` без нового поиска. Ответственные, действия, сроки и условия пересмотра совпадают с документом. Claude Code перевёл срок «через две недели от даты запроса» в «примерно 27.11.2026».
- **Проверка 3.** Обе среды назвали спорным устойчивый высокий отток одиночек: около 6,2 % в месяц стало 3,3 % в октябре при том же тарифе. Подтверждение разового мартовского всплеска у салонов на 2–5 мастеров не назвала ни одна. До выбора `outputs/` не менялись, кроме `accounting.md` в Codex. После выбора есть снимки `.history/<N>/` с верной нумерацией (в Codex — 3, после двух прежних пересмотров), запись «было и стало», новое согласие с порогами. Проверка выхода пройдена.
- **Codex вернулся к выбору направления.** По рекомендованному пути он заново сравнил варианты и спросил, какое направление выбрать. Это верно: выбор делает человек. Скрипт такой ветки не предусматривал, поэтому выбор и согласие посланы вручную в ту же беседу, с теми же флагами изоляции (`r5`, `r6` в журнале). После этого добавлена реплика `r3b`.
- **Проверка 4.** Claude Code сохранил checkpoint по шагу 4 процедуры: этап, ожидание выбора, затронутые части. Предложенных путей и рекомендации в нём не было, они остались в ответе чата. Codex в новом чате честно сказал, что рекомендация не сохранилась, и дважды попросил уточнить путь. Пересмотр не завершён. При этом он записал согласие и снял копию, не зная пути.

Причины неудач — в процедуре, а не в модели: обе среды выполнили её буквально.

1. Шаг 4 не требовал сохранять предложенные пути. Ответ «согласен с рекомендацией» в новой беседе исполнить нельзя.
2. Форма ответа требовала назвать только опровергнутые выводы, а подтверждённые — нет.

## Исправление

В `agent/workflows/revision.md`:

- шаг 4: в `open_items` сохраняются затронутые части и каждый предложенный путь одной строкой, рекомендованный помечен;
- шаг 5: если путь нельзя однозначно понять ни из беседы, ни из `open_items`, агент переспрашивает и ничего не записывает;
- «Что сказать пользователю»: новый пункт — какие действующие выводы о тех же показателях и сегментах новые данные подтверждают, с цифрами.

## Повтор навыка: коммит 7 ветки PR №54

Codex, три реплики, кейс до `done`: навык и процедуру пользователю он больше не называл, служебных слов в ответах нет. Остальное как на коммите 6 ветки PR №54: оба вывода названы, до выбора `outputs/` не менялись, запись `Пересмотр 3` из семи строк, проверка выхода проходит. Новое согласие не понадобилось: проверка выхода прошла после третьей реплики.
