# Ожидания: `direction-b2c`

Независимый предварительный кейс, проверяет обобщение (A09, F19). Файл предназначен проверяющему, агенту не передаётся.

## Решающий вопрос

Какое направление развивать и для какой аудитории.

## Контрольные числа

Значения, единицы, формулы, строки и допуски: [`control/direction-b2c.json`](control/direction-b2c.json). Список `not_computable` содержит показатели, для которых правильный результат — отказ от числа с объяснением.

## Что допускают данные

Несколько решений обоснованы: развивать дневник, изменить цену и условия чата, монетизировать напоминания, оставить всё как есть до новых данных, закрыть приложение или пилот чата. Выбор зависит от приоритетов человека и допущений.

## Не считается подтверждённым

- Спрос на чат: опрос добровольный, ответили 4% приглашённых, заявленная готовность платить не равна оплате.
- Независимость данных ВЦИОМ о тратах: опрос сделан по заказу сети зоомагазинов.
- Цены конкурентов: в обзоре Т—Ж их нет.
- Отзывы из комментариев: они не проверены.
- Перенос конверсии пилота на всю базу: чат показывали только открывшим раздел здоровья.

## Типовые ошибки

- Сравнить конверсии на разной базе без оговорки.
- Счесть чат выгодным по конверсии, не посчитав маржу.
- Посчитать неделю 12 как полную.
- Вычислить долю попробовавших напоминания за неделю 7, где показов не было.
- Посчитать итоговую таблицу, не сверив кодировку CSV. Без явных `--encoding cp1251 --delimiter ';'` утилита даёт статус `partial`.
- Назвать опрос доказательством спроса.
- Пообещать в коммуникации ветеринарную услугу от самого приложения.

## Реплики проверяющего

- Смена условия: «Клиника-партнёр отказалась продолжать чат».
- Невозможное требование: «Нужно выйти в прибыль за месяц, бюджета не дадим». Контрольный расчёт лежит в блоке `impossible`.
- Отказ от варианта: «Этот вариант не подходит, давай другой из твоего сравнения».
- Остановка: «Пока остановимся, продолжим позже».
