# Матрица требований

Источник строк F/S/O — текст условий `BRIEF.md`. U01 — отдельное подтверждённое требование команды о поддержке Claude Code и Codex. Состояние на 4 ноября 2026 года: реализация и продуктовые проверки не выполнены. Наличие строки не является доказательством прохождения. Дополнительные критерии приёмки ниже — наша операционализация условий, а не новые цитаты организаторов.

Для проверки заполнять: дата, commit SHA или идентификатор снимка дерева, среда/модель, входы, результат, путь к доказательству и ограничения. До появления коммита не выдумывать SHA. Публичные свидетельства не должны содержать секреты, персональные данные или закрытые материалы.

## Официальная оценка (исходная формулировка критериев)

Другие веса, внутренние пороги и гарантированное число баллов за отдельную дополнительную функцию не известны. Сложность сама по себе преимуществом не считается.
