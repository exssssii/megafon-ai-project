# Лимиты, чтение страниц и время: D08, D11, D16

Статус: реализовано, живьём не проверено. Проверка в обеих средах входит в B12.

## Задача

Три замечания держались на процедуре: лимит исследования, дословность сохранённых страниц и время работы. Нужно перевести их на механику там, где среда это позволяет, а что нельзя, назвать прямо.

## Что позволяют среды

| Возможность | Claude Code | Codex |
|---|---|---|
| Перехват поиска и чтения страниц хуком | Есть, `PreToolUse` с отказом | Нет: `web_search` выполняется на стороне сервиса и хуков не проходит |
| Сеть у команд | Есть | Команды идут в песочнице, в B02 `curl` не прошёл TLS |

## Решения

**D08, лимит.**

- `action start` отказывает сверх лимита брифа.
- `add-web` и `fetch-web` отказывают сверх лимита источников. Лимит считает страницы сайтов с текстом: файлы пользователя и запись `--unavailable` его не расходуют.
- `fetch-web` идёт через команду, и хук его не видит, поэтому он требует открытое действие `web_read` в любой среде.
- В Claude Code хук `tools/web_guard.py` запрещает `WebSearch` и `WebFetch` без открытого действия того же вида. В Codex такого запрета нет.

Хук только читает и при своём сбое пропускает вызов. Он смотрит на незавершённые кейсы, журнал которых менялся за последние 12 часов, и отказывает, только если ни в одном нет открытого действия: параллельный чат не мешает, а после долгого перерыва первый вызов пройдёт без записи. Для разработки рядом со свежим кейсом есть `CASE_WEB_GUARD=off`.

**D11, дословность.**

- `read_material.py fetch-web` скачивает страницу сама и убирает разметку без модели. Отпечаток скачанных байтов пишется в `sha256` записи: так утилита отличает такой источник от сохранённого агентом.
- Запись через `add-web` остаётся запасным путём для страницы, которую не удалось скачать, и для Codex. Такой источник получает предупреждение `source_via_model` в `tools/evidence.py trace`.
- Открываются только публичные адреса. Адрес проверяется при самом соединении, так что смена ответа DNS и переадресация проверку не обходят. Прокси из окружения не используются. Размер и общее время ограничены, скрипты страницы не выполняются. Страница, полученная или разобранная не целиком, записывается как `partial`.

**D16, время.**

- Полное время строится только по меткам утилиты.
- `action end --interrupted` отмечает шаг, чей результат был готов до перерыва: такой шаг перерыв не прикрывает.

## Что не закрыто

- В Codex вызов инструмента без записи ничем не запрещён, а встроенное чтение может смешать текст со сводкой. Видно это только по предупреждению `source_via_model`.
- В Claude Code и в `fetch-web` одно открытое действие пропускает несколько вызовов: проверяется наличие записи, а не число вызовов.
- Отметку `--interrupted` ставит агент: без неё шаг, закрытый как `completed` после перерыва, считается работой.
- Страница на скриптах через `fetch-web` не читается, для неё остаётся запасной путь.
- Полнота журнала в целом держится на процедуре.
