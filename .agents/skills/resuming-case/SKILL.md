---
name: resuming-case
description: Продолжение работы над заведённым кейсом руководителя продукта после перерыва или в новом чате. Срабатывает на «продолжи», «где мы остановились», «вернёмся к кейсу». Только для кейса в projects/; новый запрос без заведённого кейса идёт через постановку. Не срабатывает на размытый запрос без явной просьбы продолжить («посмотри, что у нас с продуктом», «что там с продуктом»), даже если кейс в projects/ один: это постановка с одним вопросом.
---

Применяй только при работе над кейсом руководителя продукта в `projects/<case-id>/`. В режиме разработки этот навык не применяется.

Если в реплике нет явной просьбы продолжить, а только размытый вопрос о продукте, навык не применяй: действуй по пункту о размытом запросе в `agent/workflows/intake.md`, задай один вопрос и кейс не открывай.

Сначала выбери кейс по пункту о прямой просьбе продолжить в `agent/workflows/intake.md`. Затем действуй строго по разделу «Новый чат» в `agent/workflows/checkpoint.md#новый-чат`.

Если в этом чате процедура уже прочитана, не перечитывай её. Если `agent/instructions/product-mode.md` в этом чате ещё не прочитан, сначала прочитай его: его правила действуют и здесь.
